# 💸 Expense Tracker

A simple, private, real-world expense tracker for students — and anyone who's ever wondered where their money went at the end of the month.

**No sign-up. No server. No dependencies.** Your data never leaves your browser (stored in `localStorage`).

## 🔗 Live Demo

**https://muhammadmudasir-gif.github.io/expense-tracker/**

## ✨ Features

- 💰 Add expenses with amount, category, note, and date
- 📊 Live donut chart of spending by category
- 📅 Filter history by month and category
- 📈 Monthly summary: total spend, entry count, top category
- 🌙 Clean dark UI, fully responsive (works great on mobile)
- 🔒 100% private — everything stays on your device

## 🛠️ Built With

- **Vanilla JavaScript** — no frameworks, no libraries
- **HTML5 + CSS3** — custom properties, grid & flex layouts
- **Canvas API** — hand-rolled donut chart
- **localStorage** — client-side persistence

## 🚀 Run It Locally

Just open `index.html` in any browser. That's it — there's no build step or server required.
